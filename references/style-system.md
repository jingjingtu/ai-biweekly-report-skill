# AI 双周会视觉与绘图规范

## 风格定义

整体语言是“工程控制台式设计汇报”：黑色画布、荧光绿主线、点阵坐标背景、终端式眉题、低圆角数据卡和可扫描的状态标签。视觉必须服务于计划、状态和证据，不能变成赛博装饰。

## 色彩语义

| 角色 | 建议色值 | 用途 |
|---|---|---|
| 画布 | `#030605` | 页面底色 |
| 一级容器 | `#0A1713` | 目标区、章节区 |
| 二级卡片 | `#050B09` | 内容卡、证据卡 |
| 主绿 | `#00F58A` | 目标、完成、关键结论、主路径 |
| 深绿 | `#064D31` | 绿描边、路径底色 |
| 紫 | `#9B7BFF` | Coding、Skill、生成能力 |
| 青 | `#22D3EE` | 验证、连接、跨模块协作 |
| 橙 | `#FF9D32` | 风险、等待、下一阶段 |
| 主文字 | `#F2F7F5` | 标题、关键数字 |
| 次文字 | `#97AAA4` | 正文、说明 |
| 弱文字 | `#5E736C` | 元信息、辅助标注 |

绿色占可见强调的约 70%，紫/青/橙合计不超过 30%。红色仅用于明确失败或阻塞，不作为常规装饰色。

## 字体层级

- 中文：`MiSans`、`PingFang SC`、`Noto Sans SC` 依次回退。
- 英文技术标签：等宽字体 `JetBrains Mono`、`SFMono-Regular`。
- 页面大标题：56–64px / 800。
- 章节标题：34–42px / 700。
- 卡片标题：22–28px / 700。
- 指标：44–56px / 800。
- 正文：17–21px / 400，行高 1.55–1.75。
- 终端眉题与状态标签：13–16px / 600，允许轻微字符间距。
- **Figma 文字节点硬规则**：单行文字的节点高度 = `fontSize + 8px`，例如 16px 字号节点高 24px；多行文字统一 `lineHeight = fontSize * 1.6`，节点高度按实际行数计算。禁止创建或保留 `height=1px` 的文字节点。
- 生成 Figma 文本时，必须先加载字体，再设置 `characters / fontSize / lineHeight`，最后设置节点宽高；单行按 `fontSize + 8px` 固定高度，多行按 1.6 倍行高和行数给足高度。

## 网格与间距

- HTML 每页固定 `1920px × 1080px`；左右内边距 `80px`，上下内边距 `64px`。
- 不允许使用 `min-height` 代替固定高度，也不允许内容撑高页面；放不下时新增下一页。
- 主内容使用 12 列思路；常用 4 等分指标、3 等分推进卡、2 列证据区。
- 页面标题与主体间距 36–52px；模块间距 20–28px；卡片内边距 24–34px。
- 内容卡片、证据卡、下一步卡的默认内边距为 `24px 28px 24px 24px`；上/下/左必须保持 24px，右侧可根据视觉平衡扩展到 32px 或 40px，但不得小于 24px。
- 三等分卡片默认 `gap=32px`。不要使用 `space-between` 把三张卡片推到两端制造中间大空白；若业务需要稀疏排列，空白中必须加入连接线、坐标刻度、编号或状态路径等信息型装饰。
- 卡片圆角 8px，大章节 12px。禁止 20px 以上软萌圆角。
- 描边 1px，强调模块可用 2px；阴影只用于主目标框，且必须弱。

## 标志性绘图语言

1. **终端眉题**：`> Qifu B System / biweekly.md`，左上对齐，用主绿等宽字。
2. **点阵坐标**：24–32px 间距、低透明度，只用于封面或章节背景。
3. **能力路径**：深绿横带 + 文本节点 + 箭头，不画复杂流程图。
4. **阶段时间轴**：一条细线连接 3 个节点；当前绿、下一阶段紫、远期橙。
5. **状态卡**：左侧编号与标题，中部动作/证据，右侧状态或数据；不同语义用紫/青/绿细描边。
6. **进度表达**：真实百分比才画进度环/条。没有基线时用状态标签和里程碑数量。
7. **截图**：使用真实界面截图，保持清晰，配 1 句证据型图注；不使用模糊氛围图。

## 避免事项

- 不使用大面积紫色渐变、霓虹光晕、随机光球。
- 不把每个段落都装进卡片；章节背景与重复内容卡需区分。
- 不做左右各半的营销式 hero。
- 不用纯视觉插画替代真实交付证据。
- 不为了填满页面重复同一项进展。
- 不把多页内容压缩成长页，也不通过缩小到 18px 以下来硬塞内容。
- 不允许文字节点高度为 1px，不允许多行正文使用单行高度。
- 不允许三卡之间出现没有语义、没有装饰、没有连接关系的大块空白。
